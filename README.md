# 观盘 Pro · SwiftUI 原生重写

这是观盘 Pro 的 SwiftUI 原生重写工程。原有 HTML 与 Capacitor 工程保留，不会覆盖。它目前是迁移中的原生源码基线，不是可安装的 IPA，也没有经过 Xcode 编译或真机验证。

当前源码包含：分别记录 ETF/证券与场外基金持仓，新增/编辑/删除，记买卖流水并用加权成本核算已实现盈亏，ETF/证券逐笔选择是否联动现金，记录每日资产快照、按月查看快照覆盖区间收益并扣除外部现金流、按月查看有类别标记的 ETF/证券已实现盈亏（日级流水汇总），设置每项持仓目标仓位并查看相对总资产的偏差金额、读取旧版 ETF 前十大快照统计持仓重叠、根据目标权重试算 ETF 新增资金整手分配、按已公布基金净值回放历史月定投并对照同期一次性投入、记录并复盘交易计划、静态持仓压力测试、按定投计划估算未来 30/90 天投入，并导入/导出 JSON。现金联动买入会检查余额；交易流水带资产类别，避免 ETF 与基金代码相同时误改另一类持仓；行情刷新只请求自选和 ETF/证券，不会把场外基金代码当作股票报价；新增 ETF 输入六位代码后会尝试查询名称与现价，接口不可用时可手动填写。基金页已接入天天基金公开 JS 中的已公布净值历史并保存最多 1800 个点/只；支持录入基金现金分红或红利再投资；现金可选择是否加入参考现金，红利再投资会同步增加份额和成本。基金可按合同自设赎回费率档，依据已知申购/赎回/再投批次，可选先进先出、后进先出或优先低费率估算赎回费用，并将所选批次记入本地流水；若份额批次或对应费率不完整则拒绝估算，实际扣费与销售平台的批次确认仍须手动核对。自选与 ETF 可设价格上穿/下穿一次性本地通知；创建提醒时会请求 iOS 通知权限，行情刷新触发后自动停用，可手动重启。自动定投支持每日、每周、每两周、每月本地记账，按对应实际净值和可配置申购费率（默认 0.15%）计算份额与加权成本，不下单、不扣参考现金；周期遇休市按可用净值顺延，缺数据不造价，并将外部定投额纳入快照收益调整；移除基金或修改代码会停止旧计划；若当天已有快照，基金净值更新后会同步重算该快照，但不会自动新建快照。需 iPhone 实测接口网络可达性。原网页文件保持原样；使用配套的“原生迁移增强”网页导出完整 JSON 时，可一并迁移本机已缓存的基金净值历史（旧格式备份未包含的缓存历史无法从该备份恢复）、已公布数据、定投计划及已记期次、基金流水、价格提醒、网格预设与原始成交记录、个人偏好备查数据及分钟分时历史；旧版现金联动默认值、自动行情刷新间隔和深浅外观会映射到原生设置，交易画像已映射为可编辑的原生投资偏好并参与 AI 分析，其它网页专属偏好仍保留原始存档；旧网页待迁定投事件只作为档案，不自动重复入账；交易计划可迁入原生计划列表，永不自动执行。旧版 AI 凭证不导入；证券/ETF 腾讯报价解析仍需 iPhone 网络环境实测。

日内网格现可保存本地预设、导入逐分钟 CSV、按所选日期逐点回放买卖、估算固定费用并报告样本覆盖；回放资产独立于主账户。最近 20 个有效交易日达到至少 3 日后，可生成透明的规则参数建议与数据质量评分；它不是 AI 模型，也不预测收益。分时数据写入 Application Support 单独文件，已保存历史永久保留，不按交易日数或固定点数自动清理，并包含在原生完整备份中。应用前台按设置的间隔尝试刷新行情（默认 60 秒，支持关闭或 10–600 秒），并只在沪深交易时段且行情时间戳足够新时为 ETF 记录观测点；休市日仍依赖行情源正确提供时间戳。日内回放要求至少 70% 的分钟覆盖且最大间隔不超过 10 分钟。回放只有分钟采样价格，没有逐笔成交队列/分钟高低价和成交量时，穿越触发只是简化假设；因此不应被解释为真实可成交利润。

AI 账户分析使用手动触发的 OpenAI Chat Completions 兼容请求，可配置 HTTPS 接口、模型和分析要求；默认 DeepSeek 地址与模型。API 密钥保存在本机 Keychain，不进入 JSON 备份。用户点击分析后，只发送当前持仓、自选行情、现金和最近 20 条资产快照；不自动请求、不自动交易。第三方接口网络可达性、密钥权限及返回格式需要在 iPhone 上验证。

基金收益日历按历史净值和已确认的买卖/分红流水推算每日收益：买入当日不吃前一净值区间的涨跌，赎回当日仍计入当日净值变化，分红与申赎费用按日期归入；没有买入流水的旧手动持仓可补录历史起点，否则会被排除。历史起点只建立收益计算基准，不改变持仓和现金。单只净值详情里的当前份额折算不能代替真实历史收益。基金盘中估值按要求不迁移；ETF 成分重叠采用旧版静态前十大快照（截至 2026-06-30），场外基金穿透未迁。ETF 持仓已接入腾讯前复权日线图与 MA5/MA20 下一开盘信号策略回测，信号按下一交易日开盘成交并与买入持有对照，支持 60/120/250/640 日区间、蜡烛图、MA5/20/60、RSI14、MACD、区间收盘分位和最大回撤；历史 K 线本机缓存并进入完整备份，网络不可用时可读缓存。券商成交 CSV/表格可先预览、勾选并导入为 ETF/证券历史流水，重复记录会跳过，卖出盈亏以可核实的完整买入流水按加权成本计算；此导入不改变当前持仓或参考现金，也不会将历史成交重复叠加到当前余额。iOS 系统安排后台行情刷新尝试已加入（由用户开启，系统不保证执行时间或频率）；仅尝试更新证券行情和本地价格提醒，不采集分时、不运行影子盘、不更新基金净值。旧网页未发现公告抓取功能。NAS 同步现包含独立容器服务和原生客户端：兼容网页原有 `/api/data` 协议，并把原生账本、分时及日线缓存放在独立 API 空间；原生自动同步使用服务端版本比较，发现双端同时更改时暂停，不静默覆盖。首次联网且本机为空时先尝试迁移 NAS 上现存的网页账本，再建立原生同步；服务器两端都空时上传本机；本机和服务器均有不同原生数据时需要手动选择。网页与原生后续采用独立数据空间，避免不完整的逆向格式转换。容器部署说明见源码包根目录 `README-NAS同步服务器.md`。截图识别不在本次迁移范围内。日线规则提示只在打开图表时检查缓存中的历史数据，不是后台实时告警。工具页新增只读账本体检，检查持仓、交易流水、基金、现金、快照和净值历史中的结构异常，不会自动改账；旧版影子盘历史与运行中网格已迁入；应用前台收到有效行情时，会在独立虚拟资金中续算模拟成交，不影响真实账本；可单独暂停或恢复。快照只记录用户实际记录时的账面总资产；漏记日期不能由当前代码补造，旧网页快照也没有时点信息来精确处理同日现金流。定投补记依赖应用运行或手动更新净值；未来定投金额预测仅按计划日估算，不知道外部银行卡/销售平台余额；压力测试是统一跌幅静态情景，不是预测；iOS 不保证应用被关闭时准点执行。价格通知只靠前台报价更新，后台和应用关闭后没有实时行情监控。

工程目标 iOS 17+。日线由腾讯公开接口按需获取，数据源可能调整；前复权价格用于连续观察历史走势，不应用于核算真实成交或分红。生成 Xcode 工程需要在 Mac 或云端 Mac 安装 XcodeGen，然后运行 `xcodegen generate`；编译、签名、导出 IPA 需要 Apple 的 Xcode 环境与相应签名。
